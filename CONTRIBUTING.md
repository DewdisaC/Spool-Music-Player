# Contributing

Thanks for your interest in Spool Music Player.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `npm install`.
4. Make focused changes.
5. Run `npm run build` before opening a pull request.
6. Describe the problem, solution and testing performed.

## Code style

- Keep React components focused.
- Prefer clear names over clever abstractions.
- Avoid committing generated databases, uploaded media or secrets.
- Keep user-facing behavior documented when it changes.

## Pull requests

Small, focused pull requests are easier to review. Include screenshots or a short recording for significant UI changes.
